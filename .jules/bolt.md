## 2024-10-27 - Optimize correlated subqueries and PDO fetch mode
**Learning:** In the `api/customers.php` file, the `list` action used correlated subqueries within the `SELECT` clause to fetch `last_visit` and `total_purchases`. This led to an N+1 query problem, creating significant database load, especially as the number of customers grows. Additionally, `PDOStatement::fetchAll()` without arguments returns both associative and numeric keys, doubling the size of the JSON response payload.
**Action:** Replace correlated subqueries with a `LEFT JOIN` on a derived table grouped by the foreign key (e.g., `customer_id`), utilizing conditional aggregation `SUM(CASE WHEN ... THEN ... ELSE 0 END)` to apply specific filters. Always use `PDO::FETCH_ASSOC` when preparing data for JSON encoding to optimize payload size.
