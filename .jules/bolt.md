## 2024-05-18 - Avoid DATE() function on indexed columns
**Learning:** Wrapping a timestamp column in `DATE()` makes the query non-SARGable, preventing MySQL from using indexes efficiently and leading to full table scans on large tables like `sales`. Memory also confirms: "For database performance, ensure SQL queries use index-friendly SARGable range conditions (e.g., date >= ? AND date <= ?) rather than wrapping columns in functions like DATE(). When querying DATETIME or TIMESTAMP columns, append ' 00:00:00' and ' 23:59:59' to the start and end dates in PHP to guarantee inclusive bounds. Furthermore, always verify that corresponding indexes exist on the queried tables (e.g., (status, date) where the equality condition precedes the range condition) to ensure the SARGable query actually prevents full table scans."
**Action:** Replace `DATE(date) BETWEEN ? AND ?` with `date >= ? AND date <= ?` (with `00:00:00` and `23:59:59` appended to the bind variables in PHP). And make sure we have a composite index `(status, date)`.
