## 2024-05-24 - SARGable Queries and Database Indexes
**Learning:** Found that `api/analytics.php` queries for revenue and sales were wrapping datetime columns in `DATE()` functions in the `WHERE` clauses (e.g., `WHERE DATE(s.date) BETWEEN ? AND ?`). This prevents MySQL from using indexes on those columns, causing full table scans. Also observed that `database/dental_pos.sql` had zero indexes for common date filtering columns.
**Action:** Replaced `DATE(date) BETWEEN ? AND ?` with index-friendly SARGable queries: `date >= ? AND date <= ?`, manually appending time bounds (`00:00:00` and `23:59:59`) in PHP. Added composite index `(date, status)` to `sales` table and an index on `created_at` for `customers` table to immediately utilize the SARGable structures and significantly speed up dashboard and analytics performance over large datasets.
