## 2024-09-12 - Eliminate N+1 Correlated Subqueries via Left Join Derived Tables
**Learning:** Correlated subqueries in the SELECT clause (e.g., `(SELECT COUNT(*) FROM sales WHERE customer_id = customers.id)`) cause N+1 database queries, killing performance as table size grows. While converting to `LEFT JOIN` on grouped derived tables is efficient for unfiltered endpoints, care must be taken to include `COALESCE(val, 0)` to handle cases where there are no related rows. Also, if the outer query has dynamic filters, those must be pushed down to the derived table to avoid full scans.
**Action:** Always refactor correlated subqueries into `LEFT JOIN` on derived tables in listing APIs, using `COALESCE` for default values, but thoroughly verify that any `WHERE` clauses from the outer query are matched in the inner derived queries.
