## 2026-08-15 - Removed DATE() wrapper in analytics API for SARGability
**Learning:** In the `analytics.php` API endpoints, dates were being queried using `WHERE DATE(s.date) BETWEEN ? AND ?`. This breaks SARGability (Search Argumentable), meaning the database cannot use an index on the `date` column effectively since a function `DATE()` is being applied to it.
**Action:** Replaced `DATE(date) BETWEEN ? AND ?` with `date >= ? AND date <= ?` and manually appended ` 00:00:00` to the start date and ` 23:59:59` to the end date parameter in PHP. This allows MariaDB/MySQL to use indexes on the `date` column, providing a measurable performance improvement for analytics queries, especially as the `sales` table grows. Note: SARGability optimization was only applied to `WHERE` clauses to avoid breaking aggregation in `GROUP BY`.
