## 2024-09-17 - Missing ARIA Labels on Icon-only UI Buttons and Modal Close Controls
**Learning:** Numerous dynamically rendered modals (`btn-close`) and interactive widget controls (like `btn-add-category`, `btn-remove-image`, etc.) in the `.html` templates were missing accessible labels. Because localization is handled dynamically via `App.t()` utilizing data attributes on standard spans, standalone `<button>` components with pure icon layouts `fas fa-*` without inner spans remain un-translatable and screen-reader unintelligible by default unless their `aria-label` attributes are added AND targeted for localized updates (`data-i18n-target="aria-label"`).
**Action:** Always ensure that UI components containing only icons include a meaningful `aria-label`. For systems with custom data-attribute driven i18n, bind the translation to the `aria-label` attribute (e.g. `data-i18n-target="aria-label"`) so that screen readers can convey the correct function in the user's current language.
